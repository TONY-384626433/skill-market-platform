# 5 分钟原型演示操作手册

> 演示策略: 场景化故事线 —— "张工的一天"
> 角色分配: 1 人操作 + 1 人解说

---

## 演示环境准备

- [ ] 本地 Docker Compose 全栈启动 (PostgreSQL + Redis + ES + MinIO)
- [ ] 后端 API 启动: `cd backend && go run cmd/main.go`
- [ ] 前端启动: `cd frontend && npm start`
- [ ] 4 个种子 MCP Server 启动 (各在一个终端)
- [ ] 浏览器打开 http://localhost:3000
- [ ] 准备录屏软件 (OBS / Camtasia) 作为备用
- [ ] 准备截图文件夹 (每个页面的静态截图作为兜底)

---

## 演示剧本 (逐秒剧本)

### 场景 0: 开场 — 市场首页 (0:00 - 0:30)

```
操作步骤:
1. 浏览器打开 http://localhost:3000

月活用户 150+ 人。"

如果现场网络故障:
→ 直接切到截图文件夹, 展示 01-homepage.png
```

### 场景 2: 查看技能详情 + 一键安装 (1:00 - 1:45)

```

他点击'一键安装'——
系统 3 秒内完成了:
1. 生成独立 API Token
2. 权限自动配置
3. 依赖检查完成

Token 只显示一次。张工点击复制。

这个技能现在就是他工具箱的一部分了。"
```

### 场景 3: 在 Dify 中使用技能 (1:45 - 2:30)

```

"更关键的是 —— 安装后, 技能自动注册到了 Dify。

张工在 Dify 的工具列表里,
直接就能看到'数据库智能巡检助手'。

他拖到工作流里, 配置好:
每天早上 8 点自动巡检 → 生成报告 → 推送钉钉。

点一下运行 —— 
巡检报告、健康评分、问题列表, 全部自动生成。

从搜索到上线, 不到 3 分钟。
而原来要 2 周。"
```

### 场景 4: 开发者李工上架新技能 (2:30 - 3:30)

```
操作步骤:
1. 点击顶部导航"开发者"
2. 进入开发者工作台
3. 选择"MCP Server"形态
4. 填写技能信息:
   - 名称: "应急演练自动化"
   - 分类: 智能运维
   - 描述: "自动触发应急演练流程, 记录演练结果"
5. 提交审核
6. 展示审核流水线动画 (或用截图替代):
   - ✅ 格式校验通过
   - ✅ 安全扫描通过
   - ✅ 功能验证通过
7. 审核通过, 技能出现在市场中

解说词:
"再看开发者视角。

李工是安全团队的, 
他做了一个'应急演练自动化'技能。

登录开发者工作台,
选择'MCP Server'形态,
填写基本信息, 提交。

不需要人工排队审批 —— 
自动化审核流水线:

格式校验 ✓ — 安全扫描 ✓ — 功能验证 ✓

三关全过, 技能自动上架。
现在全行 150+ 同事都可以在市场中找到并使用它。"
```

## 演示应急方案

### 方案 A: 全部在线 (最优)
- 按上述剧本操作

### 方案 B: 部分故障
- API 挂了 → 切到截图
- 数据库挂了 → 切到截图
- 任何页面加载不出来 → 切对应截图

### 方案 C: 完全离线 (最坏)
- 纯使用截图文件夹 (按 1-6 编号)
- 结合提前录好的 5 分钟视频播放
- 解说词和停顿与视频同步
